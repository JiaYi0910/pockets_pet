# 🐹 倉鼠大莊園 Online (Pocket Hamsters)

一個專為手機與桌面瀏覽器設計的溫馨治癒系放置養成網頁遊戲。鋪滿真實木屑與紙棉墊料，打造三大多功能生活空間，照顧活潑軟萌的倉鼠家族！

---

## 🌟 遊戲特色

### 🏡 三大多功能探索空間
- **客廳 🛋️**：鋪設厚鋪白楊木屑墊料，配置大跑輪、雙層避暑小木屋與滾珠水樽。
- **活動室 🎡**：鋪設蓬鬆無塵紙棉，提供透明砂浴沐浴盆、啃木拱橋與磨牙蘋果枝。
- **露天庭院 🌿**：野生向日葵花壇、蒲公英花草生態造景與棲木樹樁，享受大自然微風。

### 🐹 擬真倉鼠生態行為
- **腮幫藏糧與儲糧**：點擊地面投餵向日葵種子，小鼠會把種子塞進腮幫子帶回小木屋囤積。
- **自由交互**：按住小鼠可以提起換位，小鼠會自主跑輪運動、在砂盆裡滾沙洗澡、啃木磨牙與睡大覺。
- **排泄與清潔**：定期產出便便，單擊便便或使用「🧹 大掃除」一鍵清潔賺取金幣！
- **自然繁衍與愛心送養**：離線時家中有成年公母倉鼠將有機率誕生新幼鼠（家族上限 8 隻）；手帳內支援「送養」功能為鼠鼠尋找新家庭並換取愛心金幣。

### 📦 自由家園建造模式
- **家具倉庫系統**：商店購買的家具直接入庫，隨心所欲擺放到不同房間。
- **水平鏡像翻轉**：支援家具水平鏡像旋轉（`scaleX`），小木屋開門方向與跑輪朝向自由調整。
- **隨時收回重構**：場景家具一鍵收回倉庫，不佔用房間空間。

### 🎮 豐富日常玩法
- **接瓜子大作戰**：限時 20 秒迷你敏捷遊戲，左右接金幣與葵花子、閃避落石，賺取日常開銷金幣。
- **旅行手帳**：派小鼠出門背包旅行，寄回各地專屬旅遊明信片並帶回旅途收入。
- **專屬試衣舞台**：為每隻鼠鼠換上草帽、學士帽、皇冠或可愛髮夾。
- **洗腦 BGM 播放器**：內建經典輕快背景音樂，配置 iOS Safari 防靜音與自動恢復守護機制。
- **雲端存檔同步**：串接 Firebase 認證與 Firestore 雲端儲存，換設備進度不丟失。

## 🎮 操作指南

| 功能 / 動作 | 操作方式 | 效果說明 |
| :--- | :--- | :--- |
| **投餵種子** | 點擊房間地面空白處 | 消耗 1 顆庫存葵花子，小鼠會跑來吃進腮幫 |
| **互動提鼠** | 長按並拖曳倉鼠 | 將小鼠提起換位，放開後自動落地 |
| **切換房間** | 點擊畫面左右兩側導覽箭頭 | 在客廳、活動室與露天庭院間無縫切換 |
| **清理便便** | 點擊便便顆粒 / 點擊「🧹 大掃除」 | 清理並賺取 🪙 8 金幣 / 一鍵全房清掃 |
| **家具擺放** | 進入「建造模式」點擊底部倉庫卡片 | 將家具擺出至當前房間，點擊家具可翻轉或收回 |
| **離線收益** | 離開遊戲後再次開啟 | 自動計算離線跑輪金幣與新生命誕生驚喜 |

## 🛠️ 技術架構

- **前端核心**：純 HTML5、CSS3、Vanilla JavaScript（零龐大打包框架，超輕量極速載入）
- **繪圖技術**：向量 SVG 動態程式碼生成（支援高清縮放無鋸齒）
- **資料儲存**：Local Storage 本地快取 + Firebase Firestore 雲端同步
- **身份驗證**：Firebase Authentication（Email / Password 登入機制）
- **多媒體控制**：YouTube IFrame API（含手動保活防靜音機制）
